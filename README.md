# 🍴 Restaurant & Café Website (Bootstrap)  

A fully responsive **HTML + CSS + Bootstrap project** that recreates a modern restaurant and café website. The design includes a promotional banner, about section, services, featured menu items, delivery highlights, mobile app promotion, newsletter subscription, and footer with social links — all styled for a professional dining experience.  

## ✨ Features  
- **Header & Navigation**  
  - Top bar with opening hours, contact number, and special discount info  
  - Sticky navbar with brand logo and smooth scroll effect  
  - Responsive collapse menu for mobile devices  

- **Hero Banner**  
  - Eye-catching headline with promotional offer  
  - Call-to-action button for ordering food online  

- **About Section**  
  - Storytelling layout with image and text side-by-side  
  - Highlights locally crafted food services  

- **Services Section**  
  - Grid of service cards (Breakfast, Lunch, Dinner, Custom)  
  - Hover effects with styled icons  

- **Feature Section**  
  - Popular menu items with images, prices, and discounts  
  - Order buttons for quick interaction  
  - Hover animations on featured dishes  

- **Delivery Section**  
  - Promotional banner for free food delivery  
  - Call-to-action button for instant ordering  

- **App Download Section**  
  - Showcase of mobile app with download buttons (Google Play & Apple Store)  
  - Highlights app features like quick ordering and delivery tracking  

- **Newsletter Section**  
  - Subscription form with styled input and button  
  - Background image for visual appeal  

- **Footer**  
  - Quick links (Register, Offers, Affiliate, Join Team)  
  - Social media icons (Facebook, Twitter, YouTube, LinkedIn, Instagram)  
  - Copyright notice  

- **Responsive Design**  
  - Media queries for tablets and mobile devices  
  - Grid layouts adjust seamlessly for smaller screens  

- **Interactive Elements**  
  - Navbar scroll effect using JavaScript  
  - Auto-collapse navigation on link click  

## 🛠️ Tech Stack  
- **HTML5**  
- **CSS3 (Custom Styling + Responsive Design)**  
- **Bootstrap 5** (Grid, Navbar, Buttons, Utilities)  
- **JavaScript** (Scroll-based navbar effect, menu collapse)  
- **Font Awesome** (Icons)  

## 🚀 Use Cases  
- Restaurant or café landing page design  
- Practising Bootstrap and responsive layouts  
- Portfolio project showcasing modern UI/UX  
- Template for food delivery, dining, or hospitality websites
